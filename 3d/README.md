# BUTTON ROUGE — 3D-просмотр костюма

## Состав
- `index.html` — отдельная адаптивная страница на HTML/CSS/обычном JavaScript.
- `assets/costume.glb` — сюда положить готовую 3D-модель. Сам файл модели в этом комплекте не включён: его нужно получить на этапе image-to-3D и проверить.

## Локальный запуск
Из каталога проекта:
```bash
python3 -m http.server 8080
```
Открыть `http://localhost:8080`.

Не открывайте страницу через `file://`: загрузка модулей и GLB может блокироваться браузером.

## Публикация
Скопировать каталог на ваш веб-сервер в отдельный путь, например:
`/3d/costume/`
Проверить, что доступны:
- `/3d/costume/index.html`
- `/3d/costume/assets/costume.glb`

Сервер должен отдавать `.glb` как `model/gltf-binary` (обычно веб-сервер автоматически определяет MIME-тип). Нужен HTTPS для полноценной совместимости браузеров.

## Подготовка GLB из раскадровки
1. Использовать исходные изображения панелей как отдельные изображения, а не только один коллаж, если они у вас есть.
2. Попробовать image-to-3D сервис (например, Meshy или Tripo AI), загрузив наиболее информативный ракурс как основное изображение. Дополнительные ракурсы используйте только если выбранный сервис поддерживает multi-view image-to-3D.
3. Сгенерировать модель и скачать GLB/экспортировать из Blender в GLB.
4. Проверить модель в Blender или glTF Viewer: нет ли дыр, слипшихся штанин, лишних деталей, неправильной ткани, неверного масштаба и артефактов с обратной стороны.
5. Поместить файл в `assets/costume.glb`. Имя и путь можно поменять в атрибуте `src` элемента `<model-viewer>`.

## Ограничения качества
Раскадровка содержит изображения, а не измерения и исходную 3D-геометрию. Модель, созданная только по ней, является реконструкцией и может ошибаться в скрытых участках, крое, складках и мелкой фурнитуре. Для товарной точности обязательна ручная проверка; особенно внимательно сравните перед, спинку, боковые ракурсы, пояс, воротник и ширину брюк.

## Управление
- Вращение: мышь / касание.
- Масштабирование: колесо мыши / жест двумя пальцами; также есть кнопки.
- Есть быстрый переход к переднему и заднему виду, сброс и полноэкранный режим.

## Примечание о зависимости
Страница загружает `@google/model-viewer` с unpkg CDN. Для полностью автономной установки закрепите проверенную версию библиотеки и храните её локально; для production разумно использовать конкретную версию, а не плавающий URL.
