# 📱 Amnezia AWG - Полная инструкция для мобильных устройств

## ⚠️ ВАЖНО: Причины проблем с подключением

Если раньше профили не работали, это было из-за:

1. **Неоптимальные параметры сети** 
   - ✅ Теперь: MTU уменьшен с 1380 до 1280 (более стабилен на мобильных сетях)
   - ✅ PersistentKeepalive увеличен с 25s до 30s (помогает при спящем экране)

2. **Проблемы с IPv6**
   - ✅ Удалён IPv6 из AllowedIPs (может вызвать нестабильность)
   - ✅ Используется только IPv4: `AllowedIPs = 0.0.0.0/0`

3. **DNS нестабильность**
   - ✅ Оставлены два надежных публичных DNS: 1.1.1.1 и 8.8.8.8

## ✅ Проверка подключения (очень важно!)

После включения VPN проверьте следующее в течение 30 секунд:

### 1. **Latest Handshake (важнейший параметр!)**
```
✅ ДОЛЖЕН быть недавним (сейчас или несколько секунд назад)
❌ ЕСЛИ: "Never" или старше 5 минут - подключение не работает!
🔧 Решение: 
   - Переключите VPN Off/On
   - Переключитесь на другую сеть (WiFi ↔ Mobile)
   - Перезагрузите приложение
```

### 2. **RX/TX (передача данных)**
```
✅ ДОЛЖНЫ расти при использовании интернета
❌ ЕСЛИ: оба нулевые и не растут - нет трафика
🔧 Решение:
   - Откройте браузер и зайдите на любой сайт
   - Числа должны начать расти
```

### 3. **Ваш External IP**
```
✅ ДОЛЖЕН быть: 188.166.182.158
❌ ЕСЛИ: ваш реальный IP или другой - VPN не работает
🔥 Способ проверить:
   - Откройте: https://whatismyipaddress.com
   - Или: https://2ip.ru
   - Должен показать: 188.166.182.158
```

### 4. **Интернет работает**
```
✅ Откройте браузер и зайдите на любой сайт (google.com, wikipedia.org)
✅ Откройте HTTPS сайт (https://google.com)
✅ Проверьте DNS - должен работать
❌ ЕСЛИ: "Нет интернета" - проблема с подключением
```

## 🚨 Если подключение нестабильно или отваливается

### Быстрые решения (попробуйте в порядке)

1. **Переключитесь между сетями**
   ```
   WiFi → Mobile Data (и наоборот)
   Это часто помогает восстановить handshake
   ```

2. **Выключите и включите VPN**
   ```
   Off → ждите 2 секунды → On
   Посмотрите Latest Handshake - должен обновиться
   ```

3. **Перезагрузите приложение**
   ```
   Закройте Amnezia полностью (из памяти приложений)
   Откройте заново
   Включите VPN
   ```

4. **Обновите приложение Amnezia**
   ```
   App Store / Google Play → найдите Amnezia
   Если есть обновление - установите его
   ```

5. **Попробуйте другой профиль**
   ```
   Если Maha не работает - попробуйте Ya или Mama
   Может быть проблема именно с этим профилем
   ```

### Если ничего не помогает

1. Удалите профиль из Amnezia
2. Скачайте профиль заново
3. Импортируйте его заново
4. Проверьте Latest Handshake через 10 секунд
