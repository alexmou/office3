# BUTTON ROUGE — каталог + магазины + 3D

Страница на HTML/CSS/обычном JavaScript, без React. Каталог захардкожен в `CATALOG`; при выборе товара экран 3D открывается в этой же вкладке без нового окна.

## Запуск
```bash
python3 -m http.server 8080
```
Откройте `http://localhost:8080` (не `file://`).

## GLB
В объект товара добавьте `glbUrl: "https://ваш-домен/model.glb"`. URL должен быть доступен по HTTPS; для модели с другого домена настройте CORS. При пустом `glbUrl` страница товара покажет сообщение, а каталог продолжит работать.

## Данные с backend
Внизу `index.html` есть закомментированный пример `fetch("/api/catalog")`. Когда endpoint будет готов, включите этот код, заменив локальный массив данными API. Ожидается JSON-массив с вашими полями плюс необязательное поле `glbUrl`.

## Магазины и Google Maps
Справочник `STORE_INFO` содержит шаблонные описания и заглушки адреса/телефона. Перед публикацией замените на фактические данные. Карта строится через Google Maps embed по `mapQuery`; для точной метки укажите фактический адрес или координаты.

## Возможности
- фильтры: магазин, размер, `type`, `subtype`;
- полнотекстовый поиск по основным полям товара;
- экран магазина с описанием, контактами, часами и картой;
- экран товара с интерактивным GLB, вращением, масштабированием и полноэкранным режимом;
- адаптивная сетка для смартфонов.
